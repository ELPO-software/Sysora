Sysora 1.5 gives Sysora its own look: a calmer, easier-to-read interface on the Windows 11 Fluent design, in Sysora's
blue instead of the Windows accent color. Nothing moved: same pages, same navigation, same features, in both themes and
all three languages. As before, everything stays on your PC: no account, no telemetry, no network connection.

## A new look

- **Sysora blue** for buttons, switches, selections, links and progress, in place of the Windows accent color. The cyan
  to blue gradient of the icon marks the selected page in the navigation pane.
- **Layered, opaque surfaces**: a deep blue-gray (or light gray) background, cards on top, menus and dialogs above. The
  title bar and the navigation pane keep a hint of the wallpaper (Mica), tinted to match. The data no longer sits on a
  see-through layer, so its contrast no longer depends on the wallpaper.
- **Clearer hierarchy**: larger section titles, values drawn with digits of equal width (a live value no longer shifts
  sideways as it changes), and the same icon sizes and spacing on every page.
- **Rounder shapes**: 12 px cards, 8 px buttons, fields and setting rows, 16 px dialogs and flyouts.
- **Discreet motion**: details, sections and empty states fade in when they appear. Live values are never animated, and
  nothing moves when animations are turned off in Windows.

## Easier to read

- **New metric colors**: CPU blue, memory magenta, GPU orange, disk violet, network cyan. The GPU used the same green as
  "normal", the CPU the same blue as "information", and the disk orange was close to the warning color: a nearly full
  disk now stands out from the others. The new colors were checked to stay apart with the common forms of color
  blindness.
- **Status colors** (good, warning, critical, information, unknown) are kept for states only, always shown with an icon
  or a label, and reach a 4.5:1 contrast on cards in both themes.
- **Charts**: no frame, a light dashed grid, a 2 px line over a fading area. When a chart shows two lines (upload, the
  GPU in game recaps), the second one is dashed, so they differ by more than their color.
- **Tables** (Processes, App Impact) have a header band, and the dashboard's PC Health and Since yesterday cards react
  to the pointer like the buttons they are.

## Fixes

- After a theme change, status icons, colored dots and level bars on pages opened earlier kept the colors of the
  previous theme. They now follow the new theme.

## For contributors

- The design system lives in `src/Sysora.App/Themes`: `Colors.xaml`, `Tokens.xaml`, `Typography.xaml`, `Controls.xaml`
  and `Styles.xaml`, described in
  [docs/architecture.md](https://github.com/Elpo55/Sysora/blob/main/docs/architecture.md#theme). Pages use its keys,
  never literal colors, font sizes or radii; spacing follows a 4 px grid.
- New: `SysoraBackdrop` (tinted Mica), `Motion.RevealOnShow`, and the `CardButtonStyle`, `PillButtonStyle`,
  `TableHeaderStyle` and `EmptyStateCardStyle` styles.
- The metric keys keep their names (`CpuAccentBrush`...), so view models and pages that choose a brush by key did not
  change.

## Update from 1.4

Download and run the new installer: it updates Sysora in place. Your settings, local history, alerts, detected changes
and game sessions are kept. Close Sysora first, or let the installer close it.

## Install

1. Download **`Sysora-1.5.0-setup-x64.exe`** (or `-arm64` for Windows on ARM) below.
2. Run it. By default Sysora is installed for all users in `Program Files` (administrator rights needed); the first
   screen also offers **Install for me only**, which needs no administrator rights.
3. Start Sysora from the Start menu.

The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click
**More info**, then **Run anyway**. You can check the download against `SHA256SUMS.txt`.

**Requirements**: Windows 10 version 1809 or later, or Windows 11 (x64 or ARM64). Nothing else to install: the .NET
and Windows App SDK runtimes are included.
